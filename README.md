## 📂 Proyectos destacados

### 📊 Sistema de Gestión y Evaluación Académica TyT — SENA

Participación en el análisis y desarrollo de un sistema de información orientado a facilitar la consolidación, el seguimiento y la visualización de resultados de pruebas académicas tipo Saber TyT.

Entre las funcionalidades abordadas se encuentran la gestión de evaluaciones, la comparación de resultados, el procesamiento de datos y el planteamiento de paneles para instructores y administradores.

### 🛒 Plataforma de comercio electrónico

Proyecto de desarrollo web full-stack enfocado en la construcción de una plataforma de comercio electrónico, mediante tecnologías de frontend, backend y bases de datos.

He trabajado con herramientas como React, Angular, TypeScript, Node.js, Express, Prisma y MySQL, fortaleciendo mis conocimientos en el desarrollo de aplicaciones web.
